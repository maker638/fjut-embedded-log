## 卡在哪 / 怎么解决的
- `gh auth login` 报 `dial tcp 20.205.243.166:443` 连接超时
  → 原因：Windows「系统代理」只对浏览器生效，gh 是 Go 程序，只读 HTTPS_PROXY 环境变量
  → 解决：先设 `$env:HTTPS_PROXY = "http://127.0.0.1:7897"` 再登录
- `gh repo create` 报 `GraphQL: EOF`
  → 原因：VPN 节点瞬时断流，不是配置错误
  → 验证方法：`gh api graphql -f query='query{viewer{login}}'` 连测 5 次全通过，确认是偶发
- `gh repo create --clone` 报 `unable to find git executable in PATH`
  → 原因：装 Git 之前打开的终端，PATH 是旧的
  → 解决：重开终端；或将 `C:\Program Files\Git\cmd` 加进 PATH
